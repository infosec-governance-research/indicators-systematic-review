# Information Security Governance Indicators: Systematic Review

Supplementary data for a manuscript reporting a PRISMA 2020 systematic review on information security governance indicators. The manuscript is currently under peer review and describes the methods in full. To preserve anonymous review, this repository does not identify the authors.

## Files

| File | Content |
|---|---|
| `prisma_records_359.xlsx` / `.csv` | All records identified, the stage each one reached and the reason for exclusion |
| `included_studies_37.xlsx` / `.csv` | The included studies, with bibliographic data, DOI or URL, study design, quality appraisal and number of indicators extracted |
| `LICENSE` | Terms of use during peer review |

## Selection of studies

| Stage | Records |
|---|---:|
| Records identified | 359 |
| Excluded at preliminary screening | 246 |
| Not retrieved (full-text access unavailable) | 12 |
| Records entering screening and eligibility (Web of Science 45, Google Scholar 34, local collection 22) | 101 |
| Duplicates removed | 25 |
| Unique studies screened by title and abstract | 76 |
| Excluded at title and abstract screening | 36 |
| Studies assessed in full text | 40 |
| Excluded after full-text reading | 3 |
| **Studies included** | **37** |

The `Records` sheet gives the reason for each exclusion. When the same work was identified more than once, the column `Same work as` indicates the study through which it was assessed. Details of a few internal documents are withheld to preserve anonymous review.

## Retrieving a study

Use the link in the `DOI or URL` column. When no link is given, search for the title in the source indicated. Full texts are not redistributed, as they are third-party works.
